⚡ API do Claude

Necessária para o chatbot usar IA real e pesquisar online

⚠️ Não configurada — chatbot em modo simulado
Como obter a API Key:
1. Acede a console.anthropic.com
2. Cria conta e adiciona crédito (mínimo $20)
3. Vai a API Keys → Create Key
4. Cola a key aqui e guarda as configurações

🔒 Em produção (beautybot.pt):
A chave é configurada nas variáveis de ambiente do Vercel (Settings → Environment Variables → ANTHROPIC_API_KEY). Não fica exposta no código nem no browser — é 100% segura. O campo acima é usado apenas em desenvolvimento local.
💾 Segurança dos Dados

Como os teus dados são guardados e protegidos

✅ Quando publicado em beautybot.pt
Os dados ficam permanentemente guardados no browser do utilizador. Actualizações ao site não apagam os dados porque o domínio é sempre o mesmo.
⚠️ Em ficheiros locais (antes de publicar)
Ao substituir o ficheiro HTML, os dados podem perder-se. Usa sempre o botão "Exportar dados" antes de actualizar.
Procedimento recomendado ao actualizar:
1Clica em Exportar dados no menu lateral
2Substitui o ficheiro HTML pelo novo
3Clica em Importar dados e selecciona o ficheiro exportado
4Todos os dados são restaurados automaticamente ✅
